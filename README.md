# Rànquing de l'Escoleta · Club Esportiu Universitari

Mejores marcas de la temporada de los atletas de base del CE Universitari (Sub8 a Sub16), por categoría, sexo y prueba, con ficha de cada atleta y estadillos para el Campionat de Catalunya de Clubs.

Web: https://mariapiafontsere-create.github.io/ranquing-escoleta/

Los datos salen de las actas oficiales de cada competición. La página es un único archivo (`index.html`) y se actualiza cada vez que se añade un acta nueva.
